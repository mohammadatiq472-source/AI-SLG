# SLG Shell SVG Source Pack

This folder stores source SVG icons for the native SLG shell.

Status:

- Source assets only
- Safe to edit by hand
- Can be exported later to PNG or atlas textures for Godot runtime use

Current icon set:

1. `battle_report.svg`
2. `mail_notice.svg`
3. `task_board.svg`
4. `activity_seal.svg`
5. `coin_copper.svg`
6. `jade_token.svg`
7. `alliance_banner.svg`
8. `ai_emblem.svg`
9. `help_badge.svg`
10. `close_badge.svg`
11. `back_badge.svg`

Style notes:

- Base size: `64x64`
- Primary gold: `#d8b56a`
- Dark ink: `#241b12`
- Warm paper: `#f2dfb3`
- Copper accent: `#b87333`
- Jade accent: `#73d76b`

Usage notes:

1. Prefer editing these SVG source files instead of directly painting runtime PNGs.
2. For Godot UI runtime, export to PNG when texture stability matters.
3. Keep names semantic so later scene bindings stay readable.
